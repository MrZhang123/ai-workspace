# 公司分析流程（从财报到估值）

> 基于《股市真规则》《财务报表分析》《彼得林奇的成功投资》《证券分析》及相关投资笔记整理

公司分析可以分解为以下步骤，依次完成后，最终推导出公司的内在价值和合理买入价格。每一步都有"不通过则停止"的退出判断——不是所有公司都值得走完全流程。

**量化计算**：涉及财务指标计算的步骤（2/3/5/6/9），使用 `scripts/financial_calculator.py` 进行精确计算。LLM 从财报中提取原始数据，填入标准化数据结构，交由脚本计算并输出结果表格。

---

## 第一步：业务理解

> 看不懂就停。不要在自己能力圈之外冒险。

在看任何财务数字之前，先回答以下问题：

- 公司靠什么赚钱？商业模式是什么？
- 所处行业的竞争格局和发展阶段？
- 上下游关系、客户集中度？
- **这个业务是否在我的能力圈内？**

买你了解的公司 —— 彼得·林奇

---

## 第二步：成长性分析

**核心问题**：公司成长有多快？来源是什么？能否持续？

### 分析数据

- 销售收入增长率（最重要，难以伪造）
- 盈利增长率
- 对比：盈利增长是否长期超过销售增长？若是，可能是"人造增长"信号

### 可持续增长率

$$可持续增长率 = ROE \times (1 - 股利支付率)$$

反映公司在维持当前盈利能力和分红政策下的内生增长上限。实际增长率长期高于此值，说明依赖外部融资或不可持续。

### 拆解增长来源（四个来源）

1. 销售更多产品/服务（市场份额增长）
2. 提价
3. 新产品/服务
4. 收购（质量最低，需高度警惕）

### 红旗

- 盈利增长持续超过销售增长 5~10 年 → 深挖数字背后原因
- 依赖削减成本驱动增长 → 不可持续
- 依赖收购驱动增长 → 大多数收购不能给收购方股东带来正回报

## 第三步：收益性分析

**核心问题**：相对于投入的资本，公司产生了多少利润？

### 基础指标

| 指标 | 公式 | 粗略标准 |
|------|------|----------|
| **ROA（总资产收益率）** | 净利润 ÷ 总资产 | 越高越好，对比同行 |
| **ROE（净资产收益率）** | 净利润 ÷ 股东权益 | 非金融 ≥ 10%，金融 ≥ 12%；稳定 20%+ 是好机会 |
| **ROIC（投入资本收益率）** | NOPAT ÷ 投入资本 | 最全面的盈利能力指标 |
| **自由现金流率** | FCF ÷ 销售收入 | > 5% 为合格 |

其中：
- NOPAT = 营业利润 × (1 - 有效税率)
- 投入资本 = 总资产 - 流动负债（不含有息短期负债）
- FCF = 经营性现金流 - 资本性支出

### 杜邦分析（基础）

$$ROE = 销售净利率 \times 资产周转率 \times 权益乘数$$

### 高级杜邦分解（区分经营与融资）

$$ROE = 营业资产收益率 + (营业资产收益率 - 税后实际利息率) \times 净财务杠杆$$

即：

$$ROE = 营业资产收益率 + 差价 \times 净财务杠杆$$

- **营业资产收益率** = 税后净营业利润 ÷ 净资产（反映核心经营能力）
- **差价** = 营业资产收益率 - 税后实际利息率（正值说明借债创造价值，负值说明借债毁灭价值）
- **净财务杠杆** = 净债务 ÷ 股东权益

高级杜邦的意义：区分 ROE 是靠经营能力还是靠财务杠杆。差价为正时加杠杆有益，差价为负时杠杆放大亏损。

### 营运效率指标

| 指标 | 公式 | 说明 |
|------|------|------|
| **应收账款周转天数** | 365 ÷ (收入 ÷ 应收账款) | 越短越好 |
| **存货周转天数** | 365 ÷ (销售成本 ÷ 存货) | 越短越好 |
| **应付账款周转天数** | 365 ÷ (销售成本 ÷ 应付账款) | 对上游议价力 |
| **现金转化周期** | 应收天数 + 存货天数 - 应付天数 | 越短越好，负值=占用上下游资金 |
| **营业营运资本/收入** | 营业营运资本 ÷ 销售收入 | 越低越好 |

营业营运资本 = (流动资产 - 现金及等价物) - (流动负债 - 有息短期负债)

### EVA（经济增加值）

$$EVA = NOPAT - 投入资本 \times WACC$$

EVA > 0 说明公司创造了超额价值；EVA < 0 说明公司在毁灭股东价值，即使账面盈利。

### 注意事项

- ROE 可被高杠杆推高 → 必须通过高级杜邦检查"差价"是否为正
- ROE > 40% 可能不真实（拆分、回购、大规模加价等导致权益基数下降）
- 将净利润趋势与经营性现金流趋势对照，确认盈利真实性

## 第四步：竞争优势 / 护城河

**核心问题**：前两步分析出的成长性和收益性能否**持续**？

护城河是区分"暂时优秀"和"长期优秀"的关键。主要类型：

- **品牌**：定价权，消费者认知
- **转换成本**：客户迁移代价高
- **网络效应**：用户越多价值越大
- **成本优势**：规模、流程、地理位置
- **牌照 / 专利**：法规或知识产权壁垒

护城河越宽，未来现金流越可预测，估值时可使用更低的折现率。

## 第五步：财务健康状况

**核心问题**：公司的财务根基是否牢固？

### 偿债能力

| 指标 | 公式 | 标准 |
|------|------|------|
| **权益负债率** | 长期负债 ÷ 所有者权益 | 越低越好，对比同行 |
| **已获利息倍数（TIE）** | EBIT ÷ 利息费用 | 越高越好，关注五年趋势 |
| **流动比率** | 流动资产 ÷ 流动负债 | ≥ 1.5 |
| **速动比率** | (流动资产 - 存货) ÷ 流动负债 | ≥ 1.0（制造业/零售业尤其重要） |

### 现金流覆盖能力

| 指标 | 公式 | 标准 |
|------|------|------|
| **经营现金流量比率** | 经营现金流 ÷ 流动负债 | 越高越好，衡量短期偿债的现金保障 |
| **现金流量充裕率** | 经营现金流 ÷ (资本支出 + 偿债支出 + 股利) | > 1 安全，= 1 临界，< 1 危险 |
| **销售收入现金含量** | 经营现金净流入 ÷ 销售收入 | 越高说明收入"含金量"越高 |

### 现金流生命周期判断

| 阶段 | 经营现金流 | 投资现金流 | 筹资现金流 |
|------|-----------|-----------|-----------|
| 创业期 | 入不敷出 | 大额流出 | 主要资金来源 |
| 成长期 | 快速增长但不宽裕 | 流出减缓 | 依赖降低 |
| 成熟期 | 十分充裕 | 大幅增加（对外投资） | 快速下降 |
| 衰退期 | 急剧下降 | 持续下降 | 日益枯竭 |

## 第六步：揭开财务伪装（识别危险信号）

> 发现重大疑点就停。财务造假的公司不值得继续分析。

### 最简判断法

净利润趋势 vs 经营现金流趋势，若二者背离（尤其连续三年入不敷出），必有问题。

### 六大危险信号（《股市真规则》）

1. **现金流衰退** — 经营利润增长但经营性现金流下降
2. **连续的非经常性费用** — 可能隐藏不良信息
3. **连续收购** — 财务数据被反复改写
4. **CFO 或审计师离开**
5. **应收账款增长快于销售收入** — 回款出问题
6. **变更赊销付款条件**

### 七大其他缺陷

- 投资收益充盈利润
- 养老金问题（计划资金不足或利用养老金调节利润）
- 存货增长快于销售
- 会计假设变更（折旧年限延长、坏账准备不同步）
- 费用资本化隐藏支出
- 报告利润与应税所得额差距扩大
- 季度末对收入和费用进行大额调整

### 收入操纵九大手法

1. **寅吃卯粮** — 透支未来收入
2. **以丰补歉** — 储备当期收入（利润蓄水池）
3. **鱼目混珠** — 伪装收入性质
4. **张冠李戴** — 弯曲分部收入
5. **借鸡生蛋** — 夸大收入规模
6. **瞒天过海** — 虚构经营收入
7. **里应外合** — 相互抬高收入
8. **六亲不认** — 隐瞒关联收入
9. **随心所欲** — 篡改收入分配

### 收入操纵八大预警信号

1. 应收账款的增幅高于销售收入的增幅
2. 计提巨额的坏账准备
3. 收购日前后毛利率发生大幅波动
4. 销售收入与生产能力比例失调
5. 发生大量退货
6. 与客户发生套换交易
7. 收入主要来自关联销售
8. 销售收入与经营性现金流量相背离

### 资产减值七大信号

1. 资产市价当期大幅下跌，跌幅明显高于正常预期
2. 经济、技术或法律环境发生重大不利变化
3. 市场利率或投资报酬率提高，影响资产折现值
4. 有证据表明资产已陈旧过时或实体损坏
5. 资产已被或将被闲置、终止使用或提前处置
6. 内部报告显示资产经济绩效远低于预期
7. 其他表明资产可能已发生减值的迹象

**"洗大澡"识别**：某个会计期间突然出现巨额资产减值准备，管理层将亏损归咎于新准则或制度变化，意图一次性释放风险为未来业绩"清洗"。

### 18项高风险预警因素（综合）

1. 高管人员异常变动（尤其财务高管或主办会计频繁辞职/调离）
2. 频繁变更会计师事务所（尤其被出具"不干净"审计报告后）
3. 被审计单位陷入财务困难（面临退市、银行逼债等）
4. 盈利质量与净资产质量相互背离
5. 净利润与经营现金流持续背离（尤其连续三年入不敷出）
6. 销售收入与经营现金流相互背离
7. 某个会计期间出现"大洗澡"式的资产减值
8. 将会计估计变更混淆为会计政策变更
9. 将会计舞弊解释为会计差错
10. 不合乎商业逻辑的资产置换
11. 期末发生异常的销售（尤其对新客户的大额销售）
12. 已发货未开票或已开票未发货的销售
13. 前期"销售"在本期大量退货
14. 企业合并日前后被合并企业的毛利率差异悬殊
15. 与客户频繁发生套换交易
16. 通过关联方进行购销业务
17. 报告利润与应税所得额差距扩大
18. 企业过分依赖融资机制

### 会计信息质量五维度评估

1. **公认会计原则的质量** — GAAP 本身是否存在影响分析的缺陷
2. **审计质量** — 是否违背会计准则，甚至财务欺诈
3. **准则执行质量** — 是否滥用会计准则操纵报表
4. **交易确认时间的质量** — 是否通过操纵交易时间影响报表
5. **披露质量** — 披露的信息是否足够分析经营状况

## 第七步：管理层评估

从三个维度考察：

### 报酬
- 薪酬是否与业绩挂钩？差年份是否减少奖金？
- 相对同行 CEO 薪酬水平
- 偏好：高红利 > 高薪水，限制性股票 > 大量期权

### 性格
- 是否坦率面对错误？
- 是否有关联交易/家族插手？
- 高管流动率如何？
- 是否自我吹嘘？

### 运作
- 任期内 ROE/ROA 表现（排除杠杆虚增）
- 股份数是否因期权/增发明显增长（稀释股东价值）
- 是否说到做到（承诺 vs 执行）
- 信息披露是否充分

## 第八步：空头情形分析

> 负面因素压过正面就停。

在完成以上分析后，**列举所有潜在负面因素**：
- 投资可能出什么问题？
- 别人为什么愿意卖出？
- 外部冲击的影响有多大？

目的：帮助你在坏消息出现时做出理性判断（是暂时性困难还是根本性恶化）。

## 第九步：估值

### 相对估值（多指标交叉验证）

| 指标 | 公式 | 适用场景 | 注意事项 |
|------|------|----------|----------|
| **P/S（市销率）** | 市值 ÷ 销售收入 | 盈利波动大、周期性行业 | 不能跨行业；不反映盈利能力 |
| **P/B（市净率）** | 市值 ÷ 净资产 | 金融公司、重资产公司 | 服务性公司无意义；警惕商誉虚高；结合 ROE |
| **P/E（市盈率）** | 市值 ÷ 净利润 | 通用，最常用 | 周期性公司低 P/E 可能是陷阱（利润见顶） |
| **PEG** | P/E ÷ 盈利增长率 | 成长股 | 不要为未实现的增长率多付钱 |
| **现金收益率** | FCF ÷ 企业价值 | 现金流充沛的公司 | 与债券利率比较；不适用金融股 |

**三种市盈率**：
- 静态 P/E：基于上一财年利润
- 滚动 P/E（TTM）：基于最近 12 个月利润
- 预期 P/E：基于分析师一致预期

**PEG 改良版（彼得·林奇）**：

$$PEG_{改良} = \frac{EPS增长率 + 股息收益率}{市盈率}$$

- < 1：股票比较差
- ≈ 1.5：股票还不错
- ≥ 2.0：非常值得投资

**企业价值**：

$$EV = 总市值 + 长期负债 - 现金及等价物$$

**比较基准**：同行业公司、整个市场、公司自身历史估值（最可靠）

### 内在价值估值（DCF 十年模型）

**第一步：预测未来 10 年自由现金流（FCF）** — 基于成长性分析的增长率

**第二步：将每年 FCF 折现为现值**

$$PV_n = \frac{FCF_n}{(1+R)^n}$$

**第三步：计算永续年金价值并折现**

$$永续价值 = \frac{FCF_{10} \times (1+g)}{R-g}$$

$$折现永续价值 = \frac{永续价值}{(1+R)^{10}}$$

**第四步：相加**

$$所有者权益合计 = \sum_{n=1}^{10} PV_n + 折现永续价值$$

**第五步：计算每股价值**

$$每股价值 = \frac{所有者权益合计}{总股份数}$$

**折现率的确定**：

$$折现率 = 无风险利率（国债利率）+ 风险溢价$$

风险溢价考虑因素：公司规模、财务杠杆、周期性、管理质量、竞争优势、业务复杂性

**敏感性分析**：DCF 对假设极度敏感，增长率差 2 个百分点估值可能差 30%+。**必须**用乐观/中性/悲观三组假设分别计算，得出一个估值**区间**而非单一数字。

## 第十步：确定买入价格（安全边际）

> 当前价格无折扣就等待。耐心是投资者最重要的品质之一。

### 安全边际分级

根据第四步护城河评估的结论，确定适用的安全边际档位：

| 护城河状态 | 安全边际 | 适用情形 |
|----------|----------|----------|
| 宽且稳定 | 15%~20% | 强竞争优势、盈利稳定、行业格局清晰 |
| 中等或受压 | 25%~35% | 护城河存在但面临竞争侵蚀、周期性波动、或行业变革期 |
| 窄且收缩 | 40%~50% | 护城河正被资本/技术/政策打破，未来盈利高度不确定 |
| 无护城河 | 50%~60% | 无差异化、纯价格竞争、行业进入壁垒低 |

### 买入价格计算（双底法）

买入价格需同时考虑**盈利底**和**资产底**，取两者中的较高值。仅用盈利底会导致现金充裕但暂时亏损的公司被严重低估；仅用资产底会导致轻资产烧钱公司被高估。

**盈利底（DCF法）**：

$$盈利底 = DCF估值区间中位数 \times (1 - 安全边际)$$

**资产底（清算/重置法）**：

$$资产底 = 每股净现金 + 核心业务保守估值$$

其中：
- 每股净现金 = (现金及等价物 + 短期理财 - 全部有息负债) ÷ 总股本（需统一货币单位）
- 核心业务保守估值 = 盈利业务收入 × 保守P/S倍数（通常取 0.5x~1.5x，参考同行业低谷期估值）
- 亏损业务不纳入保守估值，视为零价值
- **触发条件**：当每股净现金 / 当前股价 > 20% 时，必须计算资产底（说明现金是估值的重要组成部分）

**最终买入价格**：

$$买入价格 = \max(盈利底,\ 资产底)$$

**原理**：盈利底回答"这家公司未来能赚多少钱"；资产底回答"如果一切停滞，光凭存量资产和业务值多少钱"。两者取较高值，避免对现金充裕公司给出低于清算价值的荒谬买入价。

### 示例

假设某平台公司：DCF 中位数估值 60 元，护城河"窄且收缩"（安全边际 45%），每股净现金 23 元，核心盈利业务收入对应每股约 35 元（取 0.8x P/S）：

- 盈利底 = 60 × (1 - 45%) = 33 元
- 资产底 = 23 + 35 = 58 元
- 买入价格 = max(33, 58) = **58 元**

若仅用旧公式：60 × (1 - 60%) = 24 元——低于每股净现金，明显不合理。

---

## 买入决策

单只股票在投资组合中不应超过 15%。

## 总结：流程全景

```
财报 → 业务理解（商业模式、能力圈）→ 看不懂就停
     → 成长性（收入/利润增长、可持续增长率、增长来源拆解）
     → 收益性（ROA/ROE/ROIC/FCF + 高级杜邦 + 营运效率 + EVA）
     → 竞争优势 / 护城河（成长和收益能否持续）
     → 财务健康（负债/流动性/利息保障 + 现金流覆盖 + 生命周期判断）
     → 财务伪装识别（6大红旗 + 9大收入操纵 + 18项预警 + 会计质量5维度）→ 重大疑点就停
     → 管理层评估（报酬/性格/运作）
     → 空头情形（所有负面因素）→ 负面压过正面就停
     → 估值（相对估值多指标 + PEG改良 + DCF内在价值 + 敏感性分析）
     → 安全边际定价 → 无折扣就等待
     → 买入决策（单只不超过 15%）
```

核心原则：**不要仅因为价格便宜就买入，也不要仅因为公司优秀就忽视价格。好公司 + 合理折扣价 = 成功投资。**
